# Guerra Business Suite

Crie um aplicativo web responsivo chamado GBS — Guerra Business System.

Objetivo:

Construir a base inicial de um sistema empresarial premium para o Grupo Guerra, com visual moderno, limpo, elegante e profissional.

Nesta primeira fase, NÃO implemente regras financeiras complexas ainda. Crie apenas a estrutura visual, navegação e páginas principais.

Identidade visual:

- Nome: GBS — Guerra Business System

- Assinatura: Powered by Grupo Guerra

- Estilo: premium, executivo, moderno, minimalista

- Cores:

  - Azul-marinho profundo: #0F2747

  - Branco: #FFFFFF

  - Dourado fosco: #C8A45A

  - Cinza grafite: #2F2F2F

  - Cinza claro: #E0E0E0

- Layout inspirado em Stripe, Linear, Notion, Apple e Vercel.

- Interface com bastante espaço, cards elegantes, sombras suaves, bordas arredondadas e tipografia sofisticada.

Crie:

1. Tela de login

- Logo/nome GBS

- Texto: “Bem-vindo ao Guerra Business System”

- Campo de e-mail

- Campo de senha

- Botão “Entrar”

- Assinatura: Powered by Grupo Guerra

2. Layout interno

- Menu lateral fixo

- Topbar com saudação: “Bom dia, Gustavo”

- Botão de pesquisa global

- Botão de configurações

- Botão de modo escuro/claro

3. Menu lateral com módulos:

- Hoje

- Dashboard

- CRM

- Palestras

- Financeiro

- Agendistas

- Estoque

- Temporadas

- Relatórios

- Roadmap

- IA Guerra

- História

- Legado

- Biblioteca

- Auditoria

- Configurações

4. Página Hoje

Essa deve ser a tela inicial principal.

Mostrar:

- “Bom dia, Gustavo.”

- Frase: “Resultados extraordinários começam com pessoas extraordinárias.”

- Card grande: “❤️ Vidas Impactadas”

- Cards menores:

  - Receita prevista

  - Lucro líquido

  - Próximas palestras

  - Follow-ups pendentes

  - Estoque baixo

  - Pendências financeiras

  - Meta do mês

  - Temporada atual

5. Dashboard

Criar cards e gráficos de exemplo para:

- Receita

- Lucro

- Palestras realizadas

- Empresas atendidas

- Conversão comercial

- Ranking de agendistas

- Evolução mensal

6. Criar páginas iniciais vazias, mas bem desenhadas, para:

- CRM

- Palestras

- Financeiro

- Agendistas

- Estoque

- Temporadas

- Relatórios

- Roadmap

- IA Guerra

- História

- Legado

- Biblioteca

- Auditoria

- Configurações

Cada página deve ter:

- título

- descrição curta

- botão principal de ação

- tabela vazia ou cards iniciais

- mensagem humana quando não houver dados

Exemplo:

“Você ainda não cadastrou nenhuma palestra nesta temporada. Clique em Nova Palestra para começar.”

7. Botões principais globais:

- Novo Lead

- Nova Palestra

- Novo Lançamento

8. Responsividade

O sistema deve funcionar bem em desktop, tablet e celular.

9. Importante

- Não criar muitas funcionalidades ainda.

- Não criar banco de dados complexo ainda.

- Não implementar cálculos financeiros nesta fase.

- Priorizar base visual, organização, navegação, identidade e experiência premium.
